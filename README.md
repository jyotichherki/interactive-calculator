# 🧮 Interactive Calculator

## 📌 Description
The Interactive Calculator is a simple and user-friendly web application that performs basic mathematical calculations. It provides an interactive interface where users can calculate numbers quickly and easily.

## ✨ Features
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔄 Clear and reset functionality
- 🖱️ Interactive buttons
- 📱 Responsive user interface
- 🎨 Clean and attractive design

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start performing calculations!

## 🎯 Learning Objectives
- Understand JavaScript functions and event handling.
- Practice DOM manipulation.
- Improve HTML and CSS skills.
- Build an interactive frontend project.
